# راهنمای عملی بازبینی دیتاست قرآن — از «در انتظار بازبینی» تا «بازبینی‌شده»

**همراهِ `CONTENT_REVIEW.md`** — این سند سیاست جدیدی اضافه نمی‌کند؛ فقط مسیر عملی انجام
چک‌لیست انسانی/حقوقی و فرمان‌های دقیق را نشان می‌دهد. تا پایان این راهنما، وضعیت دیتاست
عمداً «در انتظار بازبینی» می‌ماند و تست‌های مخزن هم همین وضعیت را قفل کرده‌اند.

> **وضعیت (۸ اکتبر ۲۰۲۶):** این مسیر اجرا شده است؛ بازبینی با رکورد `meta.review`
> (تطبیق بایت‌به‌بایت متن عثمانی با دو آینهٔ مستقل و ترجمه با یک آینهٔ مستقل از فایل رسمی
> Tanzil + تأیید صریح مالک) ثبت شد و دیتاست پیش‌فرض `reviewed: true` است.
> checksum منبع‌ها در `public/quran/quran.json` و جزئیات در `CONTENT_REVIEW.md`.

## ۰) وضعیت فعلی

- فایل فعال: `public/quran/quran.json` — ۱۱۴ سوره و ۶۲۳۶ آیه، منسوب به Tanzil نسخهٔ ۱٫۱
  (مجوز متن: Creative Commons Attribution 3.0) با ترجمهٔ فارسی منسوب به محسن قرائتی
  (`fa.gharaati`).
- پیش از ۸ اکتبر ۲۰۲۶ وضعیت عمداً `reviewed: false` بود؛ اکنون آزمون
  `'phase 9 provenance: the active dataset is either fully pending or reviewed with a verifiable record'`
  در `tools/check.mjs` نگهبان هر دو حالت است: ادعای بازبینی فقط با رکورد قابل‌ردیابی، یا انتظار کامل.
- تا وقتی این وضعیت برقرار است، پنل دارالقرآن و کارت‌های آیه نشان‌های
  «نمونه — جایگزین شود» / «در انتظار بازبینی» را نمایش می‌دهند.

## ۱) دریافت فایل‌های رسمی (روی دستگاه بازبین، نه CI)

از صفحهٔ دانلود منبع (https://tanzil.net/download/) دو فایل زیر را بگیرید و با نام‌های
پیش‌فرض ابزار ذخیره کنید:

```
tools/tanzil/quran-uthmani.txt     ← متن رسم عثمانی (Uthmani)
tools/tanzil/fa_gharaati.txt       ← ترجمهٔ فارسی fa.gharaati
```

این دو فایل خام فقط برای راستی‌آزمایی محلی هستند؛ آن‌ها را کامیت نکنید
(JSON مشتق‌شده، بلوک حق‌نشر منبع را در `meta` نگه می‌دارد).

## ۲) تطبیق بی‌تغییر با نسخهٔ رسمی (گام مکانیکی)

```bash
node tools/build-quran.mjs
```

این ابزار دو فایل Tanzil را به `public/quran/quran.json` تبدیل می‌کند و در پایان، JSONِ
ساخته‌شده را دوباره به سطرهای سبک Tanzil برمی‌گرداند و **کلمه‌به‌کلمه** با فایل‌های ورودی
مقایسه می‌کند؛ هر اختلاف = خطا. موفقیت این گام یعنی «تطبیق بی‌تغییر متن عثمانی و ترجمه با
فایل رسمی» (بند ۱ چک‌لیست). توجه: ابزار عمداً `reviewed: false` می‌نویسد؛ پرچم بازبینی فقط
در گام ۴ ثبت می‌شود.

## ۳) بازبینی انسانی/حقوقی (غیرقابل خودکارسازی — قابل حذف نیست)

- بازبینِ واجد صلاحیت، متن و اعراب را با مرجع معتبر تطبیق دهد (بند ۳ چک‌لیست).
- مجوز بازتوزیع ترجمهٔ قرائتی داخل بازی **مستقل** تأیید شود؛ `translationNotice` در `meta`
  فقط یادداشت انتساب از منبع است، نه تأیید مجوز.
- مجوز هر فایل تلاوت (در صورت افزودن صوت) جدا تأیید شود؛ بدون `license` و `licenseUrl`
  صوت هرگز پخش نمی‌شود.

## ۴) ثبت پرچم بازبینی (فقط پس از گام‌های ۱ تا ۳)

در `public/quran/quran.json` فقط در بلوک `meta` ابتدای فایل، دو مقدار را عوض کنید
(هیچ آیه‌ای فیلد `reviewed` جدا ندارد، پس همین دو ویرایش کافی است):

```diff
-    "reviewed": false,
+    "reviewed": true,
-    "status": "external-unreviewed",
+    "status": "reviewed",
```

و اختیاری، برای ردیابی، همین بلوک را کامل کنید:

```json
"review": { "reviewer": "نام بازبین", "date": "2026-10-08", "note": "تطبیق با فایل‌های رسمی Tanzil + بازبینی انسانی" }
```

چرا کافی است؟ خوانندهٔ دیتاست (`normalizeAyah` در `src/game/quran/QuranDataset.js`)
`meta.reviewed` را به‌عنوان پیش‌فرض بازبینی همهٔ آیه‌ها اعمال می‌کند؛ در نتیجه
`reviewedVerseCount` برابر ۶۲۳۶ می‌شود و نشان‌های «در انتظار بازبینی» از رابط حذف می‌شوند.

## ۵) هم‌راستاکردن تست‌ها و اسناد

- `tools/check.mjs` — آزمون `'phase 9 provenance: every active Tanzil-attributed verse is visibly pending and sourced'`:
  - `meta.reviewed === false && status === 'external-unreviewed'` ← به `=== true` و `'reviewed'`
  - `stats.reviewedVerseCount === 0` ← به `=== publicQuran.verseList.length`
  - در حلقهٔ آیه‌ها: `!verse.reviewed` ← به `verse.reviewed` و assertion برچسب از
    `REVIEW_PENDING_LABEL` ← به برچسب «بازبینی‌شده».
- `CONTENT_REVIEW.md`: چک‌باکس‌های انجام‌شده را تیک بزنید و پاراگراف «محدودیت فعلی» را بازنویسی کنید.
- `public/quran/README.md`: یادداشت وضعیت را به‌روز کنید.

## ۶) راستی‌آزمایی نهایی

```bash
npm test && npm run smoke && npm run build && npm run test:pwa
```

## مسیر جایگزین (بدون لمس پیش‌فرض مخزن)

فایل بازبینی‌شده را مثلاً در `public/quran/quran-reviewed.json` بگذارید و اجرای خودتان را با
`?quran=./quran/quran-reviewed.json` باز کنید؛ پیش‌فرض مخزن برای دیگران «در انتظار بازبینی»
می‌ماند. ترتیب بارگذاری بدون تغییر کد در `public/quran/README.md` مستند است.
