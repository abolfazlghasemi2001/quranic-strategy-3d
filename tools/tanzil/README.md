# پوشهٔ محلی فایل‌های رسمی Tanzil

این پوشه در مخزن عمداً خالی است. برای «تطبیق بی‌تغییر» دیتاست (گام بازبینی)،
دو فایل متنی زیر را **بدون هیچ تغییری** از tanzil.net/download/ دریافت و همین‌جا بگذارید:

- `quran-uthmani.txt` — متن رسم عثمانی، نسخهٔ ۱٫۱
- `fa_gharaati.txt` — ترجمهٔ فارسی قرائتی (fa.gharaati)

سپس:

```bash
node tools/build-quran.mjs
```

خروجی در `public/quran/quran.json` نوشته می‌شود و هر آیه/ترجمه به‌صورت خودکار
کلمه‌به‌کلمه با همین دو فایل مقایسه می‌شود؛ هر اختلاف خطا می‌شود.
مسیر کامل بازبینی و شرایط ثبت `reviewed: true` در `CONTENT_REVIEW.md`
(بخش «راهنمای عملی انجام بازبینی») آمده است.
