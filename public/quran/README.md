# دیتاست متن قرآن (اجباری برای فازهای محتوایی)

**قاعدهٔ قطعی پروژه:** آیه و ترجمه هرگز از حافظه نوشته نمی‌شود. متن قرآن فقط باید از یک
دیتاست معتبر و قابل‌راستی‌آزمایی خوانده شود. تا زمانی که این پوشه دیتاست معتبر نداشته باشد،
بازی فقط جای‌نگهدار با برچسب «نمونه — جایگزین شود» نشان می‌دهد.

## فایل مورد انتظار

```
public/quran/quran.json
```

ساختار پیشنهادی (بر پایهٔ خروجی استاندارد Tanzil / دیتاست‌های مشابه):

```json
{
  "source": "Tanzil.net",
  "sourceUrl": "https://tanzil.net/download/",
  "license": "Creative Commons Attribution 3.0 (یا شرایط همان نسخه)",
  "version": "1.1",
  "script": "uthmani",
  "checksum": "sha256-...",
  "surahs": [
    {
      "index": 1,
      "name": "الفاتحة",
      "ayahCount": 7,
      "ayahs": [
        { "index": 1, "text": "…متن آیه با اعراب کامل…", "translation": "…" }
      ]
    }
  ]
}
```

## الزامات نمایش

1. متن آیه همیشه با کلاس `quran-text` (فونت قرآنی) و با اعراب کامل رندر می‌شود.
2. متن قرآن هرگز روی زمین بازی، روی سازه‌های قابل‌تخریب یا روی افکت نبرد قرار نمی‌گیرد.
3. هر آیه باید منبع (سوره/آیه/نسخهٔ دیتاست) را در رابط کاربری نشان دهد.
4. هیچ متن قرآنی نباید داخل کد به‌صورت ثابت (hard-coded) نوشته شود.

## افزودن فونت قرآنی

فایل فونت (مثلاً `AmiriQuran.woff2`) را در `public/fonts/` بگذارید و در
`src/ui/hud.css` یک `@font-face` به متغیر `--font-quran` اضافه کنید. پروژه به‌صورت
پیش‌فرض هیچ فایل فونت بیرونی دانلود نمی‌کند.

## پیاده‌سازی اعتبارسنجی (فاز ۲+)

- بررسی وجود فایل و صحت `checksum`
- بررسی دامنهٔ اعراب (U+064B–U+0652 و U+0670 و U+06D6–U+06ED) برای هر آیه
- نمایش خطا در کنسول و جای‌نگهدار در صورت نبود دیتاست
