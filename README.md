# شهر نور — Shahr-e Nur

بازی **شهرسازی و استراتژی سه‌بعدی موبایل‌محور** با الهام از قصه‌های قرآنی.
دوربین زاویه‌دار ثابت (سبک Clash of Clans)، رابط کاملاً فارسی و RTL، و همهٔ مدل‌ها/تکسچرها
با کد ساخته می‌شوند (بدون هیچ فایل باینری خارجی).

> **وضعیت:** فاز ۱ کامل است — پایهٔ موتور، دنیای سه‌بعدی، دوربین لمسی و HUD.

---

## ۱) اجرا

```bash
npm install
npm run dev          # http://localhost:5173
```

سایر دستورها:

```bash
npm run build        # خروجی production در dist/
npm run preview      # پیش‌نمایش خروجی build
npm run check        # تست‌های خودکار لایهٔ منطق (بدون GPU)
```

پارامتر کیفیت: `?quality=low|medium|high` (مثلاً `http://localhost:5173/?quality=low`).
پیش‌فرض به‌صورت خودکار از روی `hardwareConcurrency`، `deviceMemory` و نوع اشاره‌گر انتخاب می‌شود.

### کنترل‌ها

| ورودی | عملیات |
| --- | --- |
| یک انگشت (درگ) | جابه‌جایی دوربین روی نقشه |
| دو انگشت | جابه‌جایی + pinch zoom + چرخش |
| درگ چپ (دسکتاپ) | جابه‌جایی |
| درگ راست/وسط یا `Shift`+درگ | چرخش |
| چرخ ماوس | زوم |
| `W A S D` / کلیدهای جهت | جابه‌جایی |
| `G` / `H` / `R` / `P` | گرید / پنل توسعه / بازنشانی دوربین / توقف |
| تپ روی نقشه | انتخاب خانه (رویداد `tile:tap` با مختصات خانه) |

## ۲) ساختار پروژه

```
index.html                 صفحهٔ اصلی (canvas + متاتگ‌های موبایل)
vite.config.js             تنظیمات dev/build (host 0.0.0.0 برای پیش‌نمایش)
public/quran/README.md     قاعده و ساختار دیتاست معتبر قرآن (اجباری برای فازهای محتوایی)
src/
  main.js                  راه‌اندازی: config → engine → world → input → game → ui → loop
  data/                    داده‌های داده‌محور (JSON): world، terrain، quality، gameplay، strings.fa
  core/                    موتور و ابزارهای پایه (بدون منطق بازی)
    Config.js              خواندن/ادغام JSON، تشخیص کیفیت، کمک‌تابع‌های نقشه
    Engine.js              renderer، scene، resize/DPR، game loop، آمار، dispose
    InputManager.js        اشاره‌گر/چرخ/کلید → intent (pan، zoom، rotate، tap)
    OrbitCameraRig.js      دوربین کلش‌مانند: زاویه ثابت، inertia، محدودیت مرز و زوم
    RNG.js / Noise.js      تولید تصادفی قطعی (بذر ثابت) و نویز مقداری
    MathUtils.js           clamp/lerp/damp/smoothstep/زاویه
    GeometryUtils.js       ساخت هندسه با کد: زمین، درخت، سنگ، بوته، نشانگر
    Textures.js            تکسچر Canvas (چمن/خاک/شن) + دانه‌بندی
    Registry.js            نگه‌داری و dispose یکپارچه منابع GPU
    EventBus.js            گذرگاه رویداد + فهرست نام رویدادها
  world/                   دنیای سه‌بعدی
    World.js               مالک نورها، زمین، چانک‌ها، آسمان و نشانگرها
    TerrainMap.js          نقشهٔ منطقی: مسیرها، لکه‌های خاک، محدودهٔ رزرو مرکزی
    Placement.js           پخش قطعی درخت/سنگ/بوته با قواعد فاصله و تراکم
    Terrain.js             زمین تک‌مش با بلند تکسچرها (mask) + گرید
    Decor.js               InstancedMesh برای جنگل/سنگ/بوته (۴ draw call)
    Chunk.js               واحد چانک (آمادهٔ streaming فازهای بعد)
    SkyDome.js             آسمان گرادیانی با شیدر سفارشی
    Markers.js             نشانگرهای تپ (pool)
  game/                    منطق بازی (بدون Three.js و بدون DOM)
    Game.js                تیک ثابت، تبدیل تپ به خانه، انتشار رویداد
    GameState.js           دادهٔ خالص قابل ذخیره
  ui/                      رابط فارسی RTL
    HUD.js, DevPanel.js, QuranPanel.js, LoadingScreen.js, PerfMonitor.js, dom.js, hud.css
tools/check.mjs            تست‌های خودکار لایهٔ منطق (۲۱ تست)
```

### جداسازی لایه‌ها

- **core** هیچ‌چیز از بازی نمی‌داند (فقط موتور و ابزار).
- **world** فقط رندر می‌کند؛ دادهٔ چیدمان را از `data/` + `Placement` می‌گیرد.
- **game** هیچ‌وقت Three.js یا DOM را لمس نمی‌کند؛ فقط intent می‌خواند و رویداد می‌دهد.
- **ui** فقط از طریق `EventBus` و خواندن `engine.stats` به بقیه وصل است.

## ۳) محتوا و خط‌قرمزها

- **متن قرآن هرگز از حافظه نوشته نمی‌شود.** تنها منبع مجاز، دیتاست معتبر (مثل Tanzil) در
  `public/quran/quran.json` است؛ تا آن زمان فقط جای‌نگهدار با برچسب «نمونه — جایگزین شود»
  نمایش داده می‌شود (پنل «سیاست متن قرآن» در HUD).
- متن قرآن هرگز روی زمین، سازه‌های قابل‌تخریب یا افکت نبرد نیست و همیشه با کلاس `quran-text`
  (فونت قرآنی + اعراب کامل) رندر می‌شود.
- هیچ تصویر یا مدلی از پیامبران، ائمه و فرشتگان ساخته نمی‌شود.
- بدون قمار/جعبهٔ شانسی و بدون خشونت گرافیکی.

## ۴) کارایی

- سایهٔ یک‌باره از یک `DirectionalLight` با نقشهٔ ثابت و bias تنظیم‌شده.
- جنگل و سنگ‌ها با `InstancedMesh` (چهار فراخوان رسم برای کل پوشش گیاهی).
- زمین تک‌مش با بلند سه تکسچر روی یک mask پخته‌شده در Canvas.
- `devicePixelRatio` حداکثر ۲ (در سطح low و medium کمتر).
- سطوح کیفیت در `src/data/quality.json`: `low` / `medium` / `high`.
- بودجهٔ هدف: ۶۰fps، زیر ۱۵۰ draw call، زیر ۴۰۰ هزار مثلث (در فاز ۱: ۸ draw call و ~۱۲ هزار مثلث).

## فاز ۲ — چیدمان ساختمان و HUD

این نسخه فروشگاه فارسی، اقتصاد اولیه، اشغال گرید و جانمایی لمسی شش نوع سازه را اضافه می‌کند. ساختمان را از «ساخت‌وساز» انتخاب کنید، پیش‌نمایش را روی نقشه بکشید و در محل سبز «تأیید ساخت» را بزنید. قطعهٔ دیوار پس از هر تأیید برای ادامهٔ ردیف فعال می‌ماند؛ با «لغو» از حالت ساخت خارج شوید. لمس یک ساختمان ساخته‌شده منوی اطلاعات و ارتقا را باز می‌کند.
